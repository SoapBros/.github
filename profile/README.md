## Soap Bros Platforms

We build cloud platforms as code on Azure, AWS, Google Cloud and STACKIT. One structure, four clouds, and the tools your team already uses. Every change is a reviewed pull request that passes automated checks and a named approver before it ships.

- **Landing zones and delivery pipelines.** Networks, identity, policy and environments, repeatable from dev to prod.
- **Data and AI platforms.** Private lakehouse, governed data products, model serving, vector search and monitoring.
- **A paved road for developers.** Request forms in a developer portal instead of ticket queues.
- **Your choice of tools.** Terraform, OpenTofu, Terragrunt, Terramate, Argo CD, Kubernetes, GitHub Actions, Prometheus, Grafana, Loki, VictoriaLogs and more.

See how it works at **[soapbros.github.io](https://soapbros.github.io)**.
