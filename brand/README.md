# Soap Bros brand kit

Start with [BRANDING.md](BRANDING.md). It has the rules, and a prompt block to paste into any LLM.

| Path | What |
|---|---|
| `BRANDING.md` | The guidelines |
| `tokens.json`, `tokens.css` | Colour, type, shape and motion as data |
| `logo/` | The duck mark and the full logo sheet |
| `favicons/` | favicon.ico and PNG sizes, cropped on the duck |
| `tool-logos/` | Single-colour marks for third-party tools, with sources in `index.json` |

The logo must never be redrawn. All product names and logos of third parties belong to their owners.
